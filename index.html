Your journey starts here.

Search sample trains, make a demo reservation, check a PNR, or cancel a demo ticket — all from one simple dashboard.

Demo website: This GitHub Pages version uses sample train data stored in this browser. It is not connected to Indian Railways/IRCTC and does not create real tickets or payments. The Java console application remains in the src/ folder.
